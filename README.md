# 基于NXP i.MX RT1064 + RT‑Thread 的全向移动智能车系统

> 
> 21届全国大学生智能车竞赛人工智能视觉组参赛作品，实现地图构建、路径规划、推箱子/炸弹爆破任务全自主执行。

## 📋 项目简介

本项目基于 **NXP i.MX RT1064（600MHz）** 主控，搭载 RT‑Thread RTOS 实时操作系统，面向三轮全向移动底盘。结合视觉识别、编码器+IMU传感器融合定位，实现A*全局路径规划、BFS推箱子求解（内置死锁检测）、炸弹爆破路径推演，整套系统完成出库、地图识别、任务分配、自主执行、回库完整业务流程，用于智能车竞赛推箱子赛题。

## ✨ 核心功能特性

1. **RT‑Thread多线程实时调度**
将任务管理、串口解析、运动控制拆分为独立线程；基于RT‑Thread事件对象做线程间解耦，系统响应延迟＜50ms。
2. **分层路径规划算法**

- A*算法实现全局路径搜索，搭配Greedy‑Straighten路径抽稀，路径点数减少60%，降低跟踪运算量；
- BFS推箱子求解器，内置死锁检测逻辑，支持最多8个箱子场景自动推演求解；
- 炸弹爆破规划：动态评估墙体收益，自动选择爆破点位打通阻塞路径。

3. **全向底盘混合运动控制**

- 远距离采用纯跟踪算法，近距离切换PID位置闭环，路径跟踪精度可达3cm；
- 完成三轮全向轮运动学正解、逆解建模，支持前后、横移、原地旋转运动。

4. **多传感器融合定位**
编码器里程计与IMU660RA做互补滤波融合，修正里程计累积误差，航向角稳定控制在 ±2°。
5. **视觉联动业务逻辑**
通过UART自定义协议和OpenArt视觉模块交互，完成地图、数字、箱子目标识别，自动分配任务目标。

## 🚀 编译与烧录

### 环境依赖

- Keil MDK‑ARM
- RT‑Thread 环境（工程内已集成）

```
# 克隆仓库
git clone https://github.com/oyc521/21smart-car-Ycar.git
```

1. 使用Keil MDK打开 `project/RT1064.uvprojx`；
2. 编译工程，下载固件至i.MX RT1064主控；
3. 上电，按下 `KEY4`，自动执行Stage1 → Stage2 → Stage3全套竞赛任务。

### 按键说明

| 按键 | 功能 |
| --- | --- |
| KEY4 | 启动三关卡全自动任务（Stage1→Stage2→Stage3） |

| 命令 | 功能 |

| `test empty` | 加载空地图，机器人位置归零 |

### 参数调参

可配合思飞SeekFree上位机在线调参：

- `map speed`：轮速PID参数、最大运动速度
- `map angle`：直行角度PD参数
- `map lateral`：侧移角度PD参数
- `map tracking`：路径跟踪相关参数
