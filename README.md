基于 **NXP i.MX RT1064** 与 **RT-Thread** 的全向移动智能车系统，实现地图构建、路径规划、推箱子/炸弹任务自主执行。  
21 届全国大学生智能车竞赛人工智能视觉组参赛作品。

## 硬件平台

| 组件 | 型号/规格 |
|------|-----------|
| 主控 | NXP i.MX RT1064 (600MHz, 256KB RAM) |
| 运动底盘 | 三轮全向轮 (120° 均匀分布) |
| 姿态传感器 | IMU660RA (六轴) |
| 编码器 | 正交编码器 ×3 (1000PPR, 30:1 减速) |
| 视觉模块 | OpenArt 摄像头 (全局地图采集 + 目标识别) |
| 无线通信 | 2.4GHz 串口模块 (UART8, 115200bps) |
| 电机驱动 | PWM 控制 (17kHz) |

## 功能特性

- **多线程任务调度**：基于 RT-Thread 划分控制、UART 解析、任务管理线程，事件驱动通信，响应延迟 < 50ms。
- **分层路径规划**：A* 全局规划 + Greedy Straighten 抽稀算法，路径点数减少 60%；Sokoban BFS 推箱子求解器（含死锁检测），支持 8 箱自动推演。
- **混合控制策略**：远距离纯跟踪 + 近距离 PID 位置闭环，跟踪精度 3cm；三轮全向底盘运动学正/逆解建模。
- **传感器融合定位**：IMU660RA 与正交编码器互补滤波融合，航向角稳定在 ±2°。
- **炸弹爆破墙规划**：动态评估墙体爆破价值，打通被障碍物封堵的路径。
- **视觉识别联动**：通过 UART 协议与 OpenArt 交互，完成数字识别、箱子类型识别，自动分配目标。
